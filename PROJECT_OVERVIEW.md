# Project Overview (SafeGuard / SafetyHub) — Backend

هذا الملف معمول كـ “خريطة” سريعة للمشروع عشان أي AI agent أو مطوّر جديد يفهم المشروع بسرعة: **الهيكل**، **التقنيات**، **الـ endpoints**، و**مسؤولية كل ملف** بشكل مختصر.

> ملاحظة أمنية: يوجد بيانات اتصال DB داخل `src/main/resources/application.properties` (مثل كلمة مرور MySQL). **لا تنسخها أو ترفعها على Git**، ويفضّل نقلها لـ env variables لاحقًا.

## Technologies (اللغات/الفريموركس/المكتبات)

- **Language**: Java 17
- **Build tool**: Maven (`pom.xml`)
- **Framework**: Spring Boot 3.5.7
- **Web/MVC**: `spring-boot-starter-web`
- **Server-rendered UI**: Thymeleaf (`spring-boot-starter-thymeleaf`) + Templates تحت `src/main/resources/templates`
- **DB**: MySQL + Spring Data JPA (`spring-boot-starter-data-jpa`)
- **Validation**: Bean Validation (`spring-boot-starter-validation`) + `ValidationService` (Regex password rules)
- **JWT**: مكتبة `jjwt-*` موجودة في `pom.xml` (لكن لا يوجد implementation واضح لاستخدام JWT في الكود الحالي)
- **Lombok**: مستخدم في DTO/Services (مثلاً `@RequiredArgsConstructor`, `@Slf4j`)
- **File uploads**: Spring Multipart (مفعّل في `application.properties`) ويُستخدم لرفع avatar
- **Static resources**: `/static/**` + تخصيص خدمة `/videos/**` في `WebMvcConfig`

## Runtime & Configuration

- **Port**: 8080 (في `application.properties`)
- **DB schema**: `safety_workspace` (MySQL) + `ddl-auto=update`
- **DataInitializer**: بيعمل seed لثلاث أدوار (Manager/Admin/User) ويضيف Users ابتدائيين لو مش موجودين.

## Endpoints (Routes / API) — مع وظيفة كل واحدة

> ملاحظة: أغلب المشروع MVC (بيرجع صفحات Thymeleaf). فيه كمان شوية endpoints بتطلع JSON للـ AJAX.

### Auth & Session

- **GET `/`**
  - **Controller**: `Loginpage`
  - **وظيفته**: يعرض صفحة `Login.html`، ولو session موجودة يحوّل حسب الدور:
    - Manager → `/manager/dashboard`
    - Admin → `/admin`
    - غير كده → `/index`
  - **Params**: `lang` (default `en`), `theme` (default `dark`)

- **GET `/login`**
  - **Controller**: `Loginpage`
  - **وظيفته**: يعرض login “إجباريًا” حتى لو كان فيه session قديمة.

- **POST `/login`**
  - **Controller**: `Loginpage`
  - **وظيفته**: login عبر email/password (مقارنة مباشرة بدون hashing) ثم يخزن session attributes (`accountId`, `rulePosition`, …) ويحوّل حسب الدور.

- **GET `/logout`**
  - **Controller**: `Loginpage`
  - **وظيفته**: يمسح session ويحوّل لـ `/login`.

- **GET `/index`**
  - **Controller**: `Loginpage`
  - **وظيفته**: صفحة legacy dashboard (`index.html`) لكن الاستخدام الأساسي في المشروع هو `/dashboard` و `/manager/dashboard`.

### Employee UI (Dashboard)

- **GET `/dashboard`**
  - **Controller**: `DashboardController`
  - **وظيفته**: Employee dashboard (stats + قائمة موظفين) + فلترة/بحث.
  - **Guard**: لازم session، ولو Manager يحوّل `/manager/dashboard`.
  - **Returns**: `templates/pages/dashboard.html`

- **GET `/employees`**
  - **Controller**: `DashboardController`
  - **وظيفته**: صفحة employees cards + counts حسب status.
  - **Guard**: لازم session، ولو Manager يحوّل `/manager`.
  - **Returns**: `templates/pages/employees.html`

- **GET `/employees/{id}/detail`**
  - **Controller**: `DashboardController`
  - **وظيفته**: تفاصيل موظف واحد.
  - **Returns**: `templates/pages/employee-detail.html`

- **POST `/employees/{id}/reset-progress`**
- **POST `/employees/{id}/update-deadline`**
- **POST `/employees/{id}/drop-course/{courseId}`**
  - **Controller**: `DashboardController`
  - **وظيفتها**: حالياً “stubs” (بتضيف toast وتعمل redirect فقط).

- **GET `/courses`** → `templates/pages/courses.html`
- **GET `/games`** → `templates/pages/games.html`
- **GET `/achievements`** → `templates/pages/achievements.html`
- **GET `/reports`** → `templates/pages/reports.html` (بيمرّر stats)

### Manager UI + AJAX

- **GET `/manager`**
  - **Controller**: `ManagerController`
  - **وظيفته**: يوجّه لواجهة المدير tabbed داخل `/manager/dashboard?tab=employees`.

- **GET `/manager/dashboard`**
  - **Controller**: `ManagerDashboardController`
  - **وظيفته**: Dashboard للمدير مع tabs (overview/employees/departments...).
  - **Params**: `lang`, `theme`, `tab`
  - **Returns**: `templates/pages/manager-dashboard.html`

#### Manager JSON endpoints (AJAX)

- **GET `/manager/departments/{depId}/jobs`**
  - **Returns**: JSON list of jobs في Department (للـ dropdowns).

- **GET `/manager/user/{userId}`**
  - **Returns**: JSON object فيه user + job/department/rule + email + warningCount.

- **POST `/manager/register`**
  - **وظيفته**: إنشاء موظف (form submit) ثم redirect لtab employees.

- **POST `/manager/register`** (AJAX)
  - **Condition**: `Header: X-Requested-With=fetch`
  - **Returns**: `{ ok: true }` أو `{ ok: false, error }`

- **POST `/manager/update`** + **POST `/manager/update`** (AJAX بنفس header)
  - **وظيفته**: تعديل بيانات موظف/مستخدم (وممكن تغيير role/job/email/password).

- **POST `/manager/delete`** + **POST `/manager/delete`** (AJAX بنفس header)
  - **وظيفته**: حذف user + account المرتبطة.

- **POST `/manager/warn`**
  - **Type**: JSON body
  - **وظيفته**: يزيد warningCount؛ لو وصل 3 يحذف الموظف تلقائيًا (Auto-terminate).

- **POST `/manager/department/update`** + (AJAX variant)
- **POST `/manager/department/create`** (AJAX فقط)
- **POST `/manager/department/delete`** + (AJAX variant)
  - **وظيفتها**: CRUD على departments من لوحة المدير.

### Admin Panel (CRUD على كل الكيانات تقريبًا)

- **GET `/admin`**
  - **Controller**: `AdminController`
  - **Guard**: لازم `rulePosition=Admin`
  - **Returns**: `templates/admin.html`
  - **Loads**: users, managers, employees, rules, departments, jobs, courses, categories, modules, videos

- **POST `/admin/user/assignRule`**
  - **وظيفته**: Assign/Remove rule لمستخدم.

- **POST `/admin/manager/create`**, **`/admin/employee/create`**
- **POST `/admin/manager/update`**, **`/admin/employee/update`**
- **POST `/admin/manager/delete`**, **`/admin/employee/delete`**
  - **وظيفتها**: CRUD على users (مع validation على username/email/password).

- **POST `/admin/rule/create`**, **`/admin/rule/update`**, **`/admin/rule/delete`**
- **POST `/admin/department/create`**, **`/admin/department/update`**, **`/admin/department/delete`**
- **POST `/admin/job/create`**, **`/admin/job/update`**, **`/admin/job/delete`**
- **POST `/admin/course/create`**, **`/admin/course/update`**, **`/admin/course/delete`**
- **POST `/admin/courseCategory/create`**, **`/admin/courseCategory/update`**, **`/admin/courseCategory/delete`**
- **POST `/admin/courseModule/create`**, **`/admin/courseModule/update`**, **`/admin/courseModule/delete`**
- **POST `/admin/moduleVideo/create`**, **`/admin/moduleVideo/update`**, **`/admin/moduleVideo/delete`**

### Events (Pages + Notifications API)

- **GET `/events`**
  - **Controller**: `EventsController`
  - **وظيفته**: صفحة events + فلترة (ALL/TRAINING/WARNING) + counters.
  - **Returns**: `templates/pages/events.html`

- **POST `/events/create`**
- **POST `/events/{id}/update`**
- **POST `/events/{id}/delete`**
  - **وظيفتها**: CRUD للـ SafetyEvent + Toast messages.

- **GET `/api/events/latest`**
  - **Type**: JSON
  - **وظيفته**: polling للـ notifications (يرجع آخر N events) — بيرجع empty لو مش authenticated.

### Profile (User settings)

- **GET `/profile`**
  - **Controller**: `ProfileController`
  - **Returns**: `templates/pages/profile.html`

- **POST `/profile/update`**
  - **وظيفته**: تحديث name/phone/email/gender + تحديث session.

- **POST `/profile/avatar`**
  - **وظيفته**: رفع avatar وتخزينه تحت `static/uploads/avatars/` ثم حفظ path في DB + session.

### Training & Static Pages

- **GET `/training`** → `templates/training.html`
- **GET `/training/courses`** → `templates/training-courses.html`
- **GET `/login/trainingcoworker`** → redirect لـ `/training/courses`
- **GET `/fire_station`** → `templates/fire_station.html`
- **GET `/safety_alerts`** → `templates/safety_alerts.html`
- **GET `/first_aid`** → `templates/first_aid.html`
- **GET `/scenarios`** → `templates/scenarios.html`

### Misc

- **GET `favicon.ico`**
  - **Controller**: `FaviconController`
  - **وظيفته**: يرجّع 204 عشان يمنع 404 spam.

- **REST: `/api/user/*`**
  - **Controller**: `DatabaseRequestes`
  - **ملاحظة**: ده جزء “API style” منفصل عن MVC، وبيستخدم services مختلفة (فيها access للـ DB بشكل غير JPA في بعض الأجزاء).
  - **POST `/api/user/modify-password`**: تغيير password بعد التحقق من old password.
  - **POST `/api/user/apply-course`**: “apply” على Course (حالياً insert مباشر).

## File responsibilities (ملخص “كل ملف مسؤول عن ايه”)

### Root

- `pom.xml`: تعريف dependencies/plugins (Spring Boot, JPA, Thymeleaf, JWT, Lombok, MySQL…).
- `README.md`: نظرة عامة وتشغيل محلي + ملاحظات قديمة عن إصلاحات admin panel.
- `QUICK_REFERENCE.md`, `EXECUTION_SUMMARY.md`, `DELIVERY_SUMMARY.md`: ملفات توثيق مرتبطة بإصلاحات سابقة.

### `src/main/java/com/saftyhub/project1/`

- `Project1Application.java`: Main entry point + EntityScan/EnableJpaRepositories.
- `WebMvcConfig.java`: static resources config (خصوصًا `/videos/**` + MIME types mp4/webm/ogg).
- `DataInitializer.java`: seed roles/users عند startup + طباعة اسم الـ schema المتصل به.

#### `controller/`

- `Loginpage.java`: login/logout/session routing حسب role + عرض `Login.html` و `index.html`.
- `DashboardController.java`: صفحات الـ employee dashboard/employees/courses/games/achievements/reports + تفاصيل موظف.
- `ManagerDashboardController.java`: صفحة manager dashboard tabbed + تجهيز data للـ tabs + charts placeholders.
- `ManagerController.java`: عمليات الـ manager (CRUD users, departments) + endpoints JSON للـ AJAX.
- `AdminController.java`: لوحة admin + CRUD لكل الكيانات (users/rules/departments/jobs/courses/modules/videos...).
- `ProfileController.java`: صفحة البروفايل + تحديث بيانات + رفع avatar.
- `EventsController.java`: صفحة events + CRUD + API للـ notifications (`/api/events/latest`).
- `TrainingPage.java`: صفحات تدريب ثابتة + redirects بسيطة.
- `DatabaseRequestes.java`: REST API تحت `/api/user/*` (تغيير باسورد، apply course…).
- `FaviconController.java`: endpoint `favicon.ico` (204).
- `GlobalControllerAdvice.java`: يضيف attributes عامة للـ templates (username/profilePic/isManager/isAdmin…).
- `JwtResponse.java`: ملف placeholder (فارغ حالياً).

#### `dto/`

- `EmployeeDto.java`: DTOs للـ employee (Summary/Detail/Stats/DeptStat + enums).
- `EmployeeMapper.java`: mapping من entity `Users` → DTOs.
- `EnrollmentDto.java`: DTO لمفهوم enrollment (إن وُجد استخدامه في الـ templates/logic).
- `ManagerActionDto.java`: DTO لأكشنز المدير (إن وُجد استخدامه).
- `SafetyEventDto.java`: DTO للـ SafetyEvent + `fromEntity`.

#### `exception/`

- `ResourceNotFoundException.java`: exception مخصص لـ 404 semantic errors.
- `GlobalExceptionHandler.java`: يمسك exceptions ويرجع `templates/error.html` + logging.

#### `model/` (JPA Entities + Enums)

- `Users.java`: user entity (username/phone/gender/joinDate/rule/job/profilePicture/warningCount…).
- `Account_information.java`: account info entity (email/password) مرتبطة بالـ userId.
- `Rules.java`: roles/rules entity.
- `departments.java`: departments entity.
- `job_information.java`: jobs entity (مرتبط بـ department).
- `courses_information.java`: courses entity (title/description/difficultyStatus…).
- `courses_category.java`: course categories entity.
- `course_modules.java`: course modules entity (مرتبط بـ course).
- `ModuleVideos.java`: module video entity (videoPath + module).
- `SafetyEvent.java`: events entity + enum `EventType` + fields (severity/targetDepartment…).
- `Position.java`, `ETRole.java`: enums/role helpers (حسب استخدامهم في الكود).
- `account_activity.java`, `account_change.java`, `account_videos.java`: جداول/كيانات إضافية مرتبطة بالحساب/النشاط/الفيديوهات.

#### `repository/` (Spring Data JPA)

- `UserRepository.java`: queries على users (بما فيها `findAllWithJobDepAndRule`).
- `AccountRepository.java`: queries على account_info + delete native by accountId.
- `RulesRepository.java`: roles queries.
- `DepartmentRepository.java`: departments queries (بما فيها `findMaxDepId`).
- `JobRepository.java`: jobs queries (بما فيها `findByDepartmentId`).
- `EmployeeRepository.java`: (لو منفصل عن UserRepository لسيناريوهات معينة).
- `SafetyEventRepository.java`: events queries (filter/count/sort).
- `CoursesInformationRepository.java`: courses CRUD.
- `CoursesCategoryRepository.java`: category CRUD.
- `CourseModulesRepository.java`: modules CRUD.
- `ModuleVideosRepository.java`: module videos CRUD.
- `CourseRepository.java`, `CourseEnrollmentRepository.java`: كيانات/عمليات courses/enrollments (حسب استخدامهم).
- `repository/Databasecomponents/Link.java`, `Checktablevalidation.java`: helpers/low-level DB utilities.

#### `services/`

- `AdminService.java`: business logic للـ Admin CRUD (users/rules/departments/jobs/courses/modules/videos…).
- `ManagerService.java`: business logic للـ Manager (register/update/delete users + departments ops + lookups).
- `EmployeeService.java`: dashboard data + stats + department stats + profile/avatar updates.
- `SafetyEventService.java`: CRUD لـ SafetyEvent + counters.
- `ValidationService.java`: password rules (Regex) + error message.
- `UserAutho.java`: login/authorization helper (مستخدم في `DatabaseRequestes`).
- `Useroperation.java`: user operations (مستخدم في `DatabaseRequestes`).
- `Enhancment.java`, `Insert.java`, `Remove_information.java`, `Searchinguserinformation.java`: low-level DB operations/queries (أسماءها تدل على direct DB actions).
- `Manageroperation.java`: عمليات إضافية للمدير (غير مستخدمة مباشرة في Controllers الأساسية غالباً).
- `services/ManagerLogic/*`: منطق manager أقدم/مجزّأ (register/remove/search employee).
- `services/Useroeprations/modifyinformation.java`: تعديل بيانات user (اسم package فيه typo: Useroeprations).

### `src/main/resources/`

- `application.properties`: إعدادات السيرفر/DB/JPA/Thymeleaf/uploads/MIME types.
- `static/css/main.css`: ستايلات UI.
- `static/js/app.js`: JS عام للـ UI.
- `static/js/notifications.js`: polling/notifications (مرتبط غالباً بـ `/api/events/latest`).
- `static/uploads/avatars/*`: ملفات avatars مرفوعة (generated).
- `static/videos/*.mp4`: فيديوهات background (served via `/videos/**`).
- `templates/*.html`: صفحات ثابتة/عامة (login/index/training...).
- `templates/pages/*.html`: صفحات رئيسية (dashboard, employees, manager-dashboard, events, profile...).
- `templates/fragments/*.html`: أجزاء مشتركة (layout/topbar/sidebar/modals...).
- `templates/components/*.html`: components (مثلاً notification dropdown).

## Quick mental model (ملخص شديد)

- **الدخول**: `/` → `POST /login` → session (accountId + role) → redirect حسب الدور.
- **Worker flow**: `/dashboard` و صفحات user.
- **Manager flow**: `/manager/dashboard` + AJAX endpoints تحت `/manager/*`.
- **Admin flow**: `/admin` + CRUD endpoints تحت `/admin/*`.
- **Events/Notifications**: `/events` + `/api/events/latest`.
